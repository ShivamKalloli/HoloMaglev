# HoloMaglev

An interactive 3D physics simulation and EdTech platform designed to visualize and compute complex magnetic levitation dynamics. 

HoloMaglev bridges the gap between theoretical physics and interactive learning by providing a high-fidelity, browser-based simulation environment. This project is backed by comprehensive technical documentation and a research paper submitted to IEEE ICIET 2026.

## 🚀 Features

* **High-Fidelity 3D Physics:** Accurate, real-time simulation of magnetic levitation forces and system dynamics.
* **Optimized Rendering Pipeline:** Engineered with custom GLSL shaders to deliver detailed visual feedback while maintaining a highly stable 60 FPS.
* **Interactive EdTech Interface:** Designed for intuitive user interaction, allowing students and researchers to manipulate variables and observe physical outcomes in real-time.

## 📥 Installation & Setup

To run HoloMaglev locally, ensure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

1. **Clone the repository:**
```bash
   git clone [https://github.com/ShivamKalloli/HoloMaglev.git](https://github.com/ShivamKalloli/HoloMaglev.git)

2. Navigate to the project directory:
    cd HoloMaglev

3. Install dependencies:
    npm install

4. Start the development server:
    npm run dev

5. Open your browser and visit http://localhost:3000 (or the port specified in your terminal).
